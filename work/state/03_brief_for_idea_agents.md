# БРИФ ДЛЯ АГЕНТОВ-ГЕНЕРАТОРОВ ИДЕЙ (ЭТАП 1)

## Главное правило
Подбирай идеи ПОД РЫНОК УЗБЕКИСТАНА, а НЕ под конкретного человека.
Соответствие основателю проверяется отдельно и позже. НЕ фильтруй идеи по «подойдёт ли
это инвестбанкиру». Не подстраивайся. Нужен МАКСИМУМ РАЗНООБРАЗНЫХ идей.

## Три ПОЛОЖИТЕЛЬНЫХ фильтра (все три обязательны)
1. **Доказанный аналог**: модель уже работает на сопоставимом рынке. Обязательно назови
   КОМПАНИЮ, СТРАНУ и РЕЗУЛЬТАТ (выручка / клиенты / раунд / выход / доля). Сопоставимые
   рынки: Казахстан, Азербайджан, Грузия, Пакистан, Египет, Индонезия, Малайзия, Вьетнам,
   Бангладеш, Кения, Нигерия, Марокко, Турция, Индия, Филиппины, Румыния 2005-2015,
   Польша 1998-2008. Развитые рынки годятся только если механика переносима.
2. **Структурное окно в РУз**: КОНКРЕТНАЯ реформа / закон / приток капитала / сдвиг спроса /
   дефицит мощности — с названием документа, датой или измеримым фактом.
   ЗАПРЕЩЕНО писать «рынок растёт», «население молодое», «цифровизация» как окно.
3. **Логично ложится на условия страны**: платёжеспособность, кадры, инфраструктура,
   регулирование, культура, язык, логистика, конвертация валюты.

## NABC обязателен для КАЖДОЙ идеи
- N (Need) — чья боль, насколько дорого им её терпеть сейчас
- A (Approach) — как именно решаем, в чём механика
- B (Benefit per cost) — выгода клиента в цифрах против цены
- C (Competition) — ближайшие игроки ПОИМЁННО + заменители («что люди делают сейчас
  вместо этого») + честное объяснение, ПОЧЕМУ место свободно

## О конкурентах — будь мягче
Рынок развивающийся, ПУСТАЯ НИША БЫВАЕТ НАСТОЯЩЕЙ. Не убивай идею только за то, что
где-то в мире есть аналог. Но обязан назвать ближайших игроков в РУз/регионе и заменители,
и объяснить механизм, почему место свободно (регуляторный лаг, малый размер рынка для
глобальных игроков, отсутствие компетенции, недавняя смена правил, культурный барьер).

## Проверка веб-поиском
Обязательно ищи: (а) есть ли уже такой игрок в РУз; (б) подтверждение окна (закон/указ/цифра).
Если что-то не подтвердилось — так и пиши: «не подтверждено».
Не выдумывай цифры. Помечай оценки словом «оценка».
