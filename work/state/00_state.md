## Задача
Найти и обосновать бизнес для запуска в Узбекистане. Результат: документ (RU) + Excel.

## Блокеры / отклонения от ТЗ
- **Meta Muse (api.meta.ai) НЕДОСТУПЕН.** Подтверждено ДВУМЯ независимыми каналами:
  1) curl через egress-прокси -> 403 на CONNECT, 3 попытки, ~0.25 c (отбивает шлюз);
     ВАЖНО: у шелла deny-by-default на весь исходящий HTTP — так же режется www.gazeta.uz
     и api.openai.com. То есть это НЕ точечный запрет Meta.
  2) WebFetch (у него отдельный, более широкий allowlist) -> EGRESS_BLOCKED,
     "Access to api.meta.ai is blocked by the network egress proxy" — здесь запрет уже адресный.
  Правила окружения запрещают обход policy-denial; способа послать POST с телом нет.
  ЗАМЕНА: состязательный субагент-критик («Внешний критик»), тот же мандат, не видит моих
  обоснований. СЛАБЕЕ внешней модели: не независим архитектурно. ПОМЕЧЕНО В ОТЧЁТЕ ПРЯМО.
